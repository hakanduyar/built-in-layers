A personal software factory: one orchestration core that routes work to the right worker and walks every change through the same gated loop — plan, ticket, implementation, automated test, independent review, human approval, merge, evidence.

The core is deliberately small and verifiable: a TypeScript control plane with zero runtime dependencies, durable persistence on Node's built-in SQLite, deterministic mock workers for testing, and a trusted local runner for real AI workers. Its constitution fixes what autonomy may never touch — production deployment and public release remain human decisions — and its integration mandate spells out the full set of conditions under which the loop may complete work on its own.

The factory's first project is itself: it develops its own repository through the same gates it will apply to everything else.
